cohesity.dataprotect.cohesity_oracle_restore module – Restore one or more Virtual Machines from Cohesity Protection Jobs

Note

This module is part of the cohesity.dataprotect collection (version 1.4.5).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cohesity.dataprotect. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: cohesity.dataprotect.cohesity_oracle_restore.

New in cohesity.dataprotect 1.3.0

  • Synopsis

  • Requirements

  • Parameters

  • Notes

Synopsis

  • Ansible Module used to start a Cohesity Recovery Job on a Cohesity Cluster.

  • When executed in a playbook, the Cohesity Recovery Job will be validated and the appropriate state action

  • will be applied.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.6

  • cohesity_management_sdk >= 1.6.0

Notes

Note

  • Currently, the Ansible Module requires Full Cluster Administrator access.

Examples

# Restore Oracle database.
- name: Restore Oracle database.
  cohesity_oracle_restore:
    source_db: cdb1
    task_name: recover_tasks
    source_server: "192.168.1.1"
    target_server: "192.168.1.1"
    target_db: cdb2
    oracle_home: /u01/app/oracle/product/12.1.0.2/db_1
    oracle_base: /u01/app/oracle
    oracle_data: /u01/app/oracle/product/12.1.0.2/db_1
