cohesity.dataprotect.cohesity_plugin module – Management of Cohesity Datastore Plugin

Note

This module is part of the cohesity.dataprotect collection (version 1.4.5).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cohesity.dataprotect. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: cohesity.dataprotect.cohesity_plugin.

New in cohesity.dataprotect 1.3.0

  • Synopsis

  • Requirements

  • Parameters

  • Notes

  • Examples

Synopsis

  • Ansible Module used to register or remove the Cohesity Protection Sources to/from a Cohesity Cluster.

  • When executed in a playbook, the Cohesity Protection Source will be validated and the appropriate

  • state action will be applied.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.6

  • cohesity_management_sdk >= 1.6.0

Parameters

Parameter

Comments

cluster

aliases: cohesity_server

string

IP or FQDN for the Cohesity Cluster

cohesity_admin

aliases: admin_name, cohesity_user, username

string

Username with which Ansible will connect to the Cohesity Cluster. Domain Specific credentails can be configured in following formats

AD.domain.com/username

AD.domain.com/username@tenant

LOCAL/username@tenant

cohesity_password

aliases: password, admin_pass

string

Password belonging to the selected Username. This parameter will not be logged.

download_location

string

Absolute path of the scripts used to store the downloaded connection plugin.

endpoint

string / required

Specifies the network endpoint of the Protection Source where it is reachable. It could

be an URL or hostname or an IP address of the Protection Source

netmask_bits

integer

Applicable when the platform type is PostgreSQL and state is present.

Is required to add the SapHana hosts to the cluster’s global allow lists.

platform

string

Type of the UDA source to be registered.

Choices:

  • "Linux" ← (default)

  • "Windows"

  • "Aix"

  • "Solaris"

  • "SapHana"

  • "SapOracle"

  • "CockroachDB"

  • "MySQL"

  • "VMWareCDPFilter"

  • "PostgreSQL"

scripts_dir

string

Absolute path of the scripts used to interact with the UDA source.

Default: "/opt"

state

string

Determines the state of the Protection Source

Choices:

  • "present" ← (default)

  • "absent"

upgrade

boolean

Determines whether to upgrade the connector plugin if already installed.

Choices:

  • false ← (default)

  • true

validate_certs

aliases: cohesity_validate_certs

boolean

Switch determines if SSL Validation should be enabled.

Choices:

  • false

  • true ← (default)

Notes

Note

  • Currently, the Ansible Module requires Full Cluster Administrator access.

Examples

# Install cohesity connector plugin on a postgresql host.
---
- cohesity_source:
    password: password
    platform: PostgreSQL
    server: cohesity.lab
    state: present
    username: admin
