Plugin Index

These are the plugins in the cohesity.dataprotect collection:

Modules

  • cohesity_agent module – Management of Cohesity Physical Agent

  • cohesity_cancel_migration module – Cancel the VM migration

  • cohesity_clone_vm module – Management of Cohesity VM Clone

  • cohesity_facts module – Gather facts about a Cohesity Cluster.

  • cohesity_finalize_migration module – Finalize the VM migration

  • cohesity_job module – Management of Cohesity Protection Jobs

  • cohesity_migrate_vm module – Migrate one or more Virtual Machines from Cohesity Migrate Jobs

  • cohesity_migration_status module – Check Sync status of objects available in the VM migration task

  • cohesity_oracle_job module – Management of Cohesity Protection Jobs

  • cohesity_oracle_restore module – Restore one or more Virtual Machines from Cohesity Protection Jobs

  • cohesity_oracle_source module – Management of Cohesity Protection Sources

  • cohesity_plugin module – Management of Cohesity Datastore Plugin

  • cohesity_policy module – Cohesity Protection Policy

  • cohesity_restore_file module – Restore Files and Folders from Cohesity Protection Jobs

  • cohesity_restore_vm module – Restore one or more Virtual Machines from Cohesity Protection Jobs

  • cohesity_restore_vmware_file module – Restore Files and Folders from Cohesity Protection Jobs

  • cohesity_source module – Management of Cohesity Protection Sources

  • cohesity_storage_domain module – Management of Cohesity Storage Domains

  • cohesity_sync_objects module – Sync objects available in the VM migration task

  • cohesity_uda_protection_group module – Management of Cohesity UDA Protection Groups

  • cohesity_uda_source module – Management of UDA Protection Sources

  • cohesity_view module – Management of Cohesity View

  • cohesity_win_agent module – Management of Cohesity Physical Windows Agent
