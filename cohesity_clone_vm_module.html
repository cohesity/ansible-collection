cohesity.dataprotect.cohesity_clone_vm module – Management of Cohesity VM Clone

Note

This module is part of the cohesity.dataprotect collection (version 1.4.5).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cohesity.dataprotect. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: cohesity.dataprotect.cohesity_clone_vm.

New in cohesity.dataprotect 1.3.0

Synopsis

  • Ansible Module used to clone the Virtual Machine.

Requirements

The below requirements are needed on the host that executes this module.

  • python >= 3.6

  • cohesity_management_sdk >= 1.6.0

Notes

Examples

# Restore a single Virtual Machine
- name: Restore a Virtual Machine
  cohesity_clone_vm:
    cluster: cohesity.lab
    username: admin
    password: password
    state: present
    name: "Ansible Test VM Restore"
    endpoint: "myvcenter.cohesity.demo"
    environment: "VMware"
    job_name: "myvcenter.cohesity.demo"
    vm_names:
      - chs-win-01

# Restore multiple Virtual Machines from a specific snapshot with a new prefix and disable the network
- name: Restore a Virtual Machine
  cohesity_clone_vm:
    cluster: cohesity.lab
    username: admin
    password: password
    state: present
    name: "Ansible Test VM Restore"
    endpoint: "myvcenter.cohesity.demo"
    environment: "VMware"
    job_name: "myvcenter.cohesity.demo"
    backup_id: "48291"
    vm_names:
      - chs-win-01
      - chs-win-02
    prefix: "rst-"
    network_connected: false
