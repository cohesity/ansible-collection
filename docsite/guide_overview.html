Overview

The cohesity.dataprotect collection provides Ansible modules for interacting with Cohesity DataPlatform.

Leveraging Python, this collection can be used from Linux or macOS control nodes, and it can manage Windows hosts through WinRM. It includes modules and example playbooks that are useful for automating common tasks and for orchestrating workflows in your environment.

The collection uses the Cohesity REST API (through the Cohesity Management SDK) to interact with the Cohesity cluster.

What the collection covers

  • Cluster information: cohesity.dataprotect.cohesity_facts.

  • Protection sources: cohesity.dataprotect.cohesity_source, cohesity.dataprotect.cohesity_oracle_source and cohesity.dataprotect.cohesity_uda_source.

  • Protection policies and groups: cohesity.dataprotect.cohesity_policy, cohesity.dataprotect.cohesity_job, cohesity.dataprotect.cohesity_oracle_job and cohesity.dataprotect.cohesity_uda_protection_group.

  • Restore and recovery: cohesity.dataprotect.cohesity_restore_vm, cohesity.dataprotect.cohesity_restore_file, cohesity.dataprotect.cohesity_restore_vmware_file, cohesity.dataprotect.cohesity_oracle_restore and cohesity.dataprotect.cohesity_clone_vm.

  • VMware migration: cohesity.dataprotect.cohesity_migrate_vm, cohesity.dataprotect.cohesity_migration_status, cohesity.dataprotect.cohesity_finalize_migration, cohesity.dataprotect.cohesity_cancel_migration and cohesity.dataprotect.cohesity_sync_objects.

  • Agents and connectors: cohesity.dataprotect.cohesity_agent, cohesity.dataprotect.cohesity_win_agent and cohesity.dataprotect.cohesity_plugin.

  • Storage: cohesity.dataprotect.cohesity_storage_domain and cohesity.dataprotect.cohesity_view.

Example playbooks for these workflows are available in the playbooks directory of the repository.
