Setup

Steps to install

  1. Make sure that the prerequisites are installed.

  2. Install the collection on the Ansible control node using ansible-galaxy:

    ansible-galaxy collection install cohesity.dataprotect

  3. Install the Python dependencies used by the modules:

    pip install -r requirements.txt

  4. Reference the collection in your plays. You can either use the fully qualified collection name for every task, or list the collection in a play:

    - name: Gather facts from a Cohesity cluster
  hosts: localhost
  collections:
    - cohesity.dataprotect
  tasks:
    - name: Gather cluster facts
      cohesity_facts:
        cluster: "{{ cohesity_server }}"
        username: "{{ cohesity_username }}"
        password: "{{ cohesity_password }}"
        validate_certs: "{{ cohesity_validate_certs }}"

    Note

    The collections keyword is optional. Using fully qualified collection names, such as cohesity.dataprotect.cohesity_facts, is recommended.

Configure the inventory

The example playbooks read the cluster address and credentials from inventory variables. See Configure your Ansible inventory for details.
